## 🚀 How to Run

Each project folder contains its own `README.md` and `requirements.txt`. Simply navigate into the specific project folder and follow the localized setup instructions.

```bash
# Example: Running the RAG PDF Assistant
cd rag_pdf_assistant
pip install -r requirements.txt
python rag_pdf_assistant.py
```
